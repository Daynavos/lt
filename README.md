<h1>Student Marks Program</h1>
<t>The goal is to get the student with the best mark in a .CSV list and display that mark and said student's student number</t>

<h2>Files</h2>
<ol>
  <li> getbest.py</li>
  <li> test_getbest.py</li>
</ol>

<p>
<h3>getbest.py</h3>
<h5>getCols()</h5>
<t>Identifies the index of the columns containing the "Student Number" and the "Mark"</t>
<h5>findTop()</h5>
<t>Identifies the student with the highest mark</t>
</p>
<p>
<h3>test_getbest.py</h3>
<t> uses unittest module to test the two functions in the getbest.py file</t>
<t> Sample files can be found in the repo</t>
</p>

<ul>
  <li>Python 3.x</li>

</ul>
